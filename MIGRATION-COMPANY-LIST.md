## How to publish these rows

1. Open the "Early Stage Grades" database in Notion
2. Add a new checkbox property called `Published` (if it doesn't already exist)
3. Filter or sort by Name to find each company above
4. Tick the `Published` checkbox for all 138 companies
5. Deploy the code changes
6. Within 5 minutes, the triage site will start showing grades from Notion

Any row with `Published` unchecked will not appear on the site, giving you an approval gate before new grades go live.
